## Setup for the Frontend of the Goldeneye Application

# Please do the following:

1. Please ensure Node is installed, after doing so within the frontend/rings folder run "npm install"

2. Create an .env file within the frontend\rings folder

3. Within the .env file enter the following 
    -> VITE_API_URL=http://(IP OF BACKEND):8080/api

4. To run the program, enter "npm run dev" to start the frontend
